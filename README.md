# Krishan Murari - Portfolio (Angular 22 + Angular Material)

Angular only, with no backend. Standalone components, signals, zoneless change detection, Material 3 theme and light/dark mode.

## Run
```bat
npm install
npm start
```
Open http://localhost:4200

## Customize
- Content: `src/app/data/portfolio.data.ts`
- Theme colors: `src/styles.scss`
- Contact form opens the visitor's email app (mailto). No server needed.

## Build & deploy
`npm run build` produces `dist/krishan-portfolio/browser/`. Host it on any static host (GitHub Pages, Netlify, Azure Static Web Apps, S3).
